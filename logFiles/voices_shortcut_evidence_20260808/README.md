# mark4.5 (VOiCES 타겟 구성) 채널 지름길 증거 — 2026-08-08

이 폴더는 **폐기된 mark4.5 구성**의 학습 결과와 그 폐기 근거를 남긴 것이다.
데이터를 SINS 기반으로 다시 만들면서 원본이 덮어써지므로 여기에 보존한다.

## 무슨 일이 있었나

2026-08-02에 만든 mark4.5 구성은 이랬다.

- 타겟 `media_talking` 930개 = **VOiCES** `distant-16k/distractors/rm4/tele` (미국 실험실 rm4, 마이크 9개)
- others 930개 = **AI Hub 71296** VS 37개 카테고리 (확성기 1개만 제외)

2026-08-08에 학습·val 평가를 돌린 결과가 이렇게 나왔다.

```
Accuracy 1.0000 / ROC AUC 1.0000 / others FPR 0.0000
media_talking P 1.0000 R 1.0000 F1 1.0000
others        P 1.0000 R 1.0000 F1 1.0000
```

**모델이 좋아서가 아니라, 타겟과 others의 녹음 출처가 완전히 갈려 있어서 채널만 구분하면
100%가 나오는 상태였다.**

## 근거

### 1. 두 분포가 통째로 떨어져 있다

```
                    min      p25      median   p75      max      sd
media_talking     0.7037   0.8853   0.8864   0.8877   0.8979   0.0129
others            0.0997   0.1063   0.1078   0.1094   0.1603   0.0057

타겟 최솟값 0.7037 / others 최댓값 0.1603 → 사이 0.5434 가 통째로 빔
겹침구간(0.35~0.65) 표본 0개 (0.0%)
threshold 스윕에서 accuracy 1.0000 동률 구간이 0.17~0.70 (54개 지점)
```

정상 버전의 겹침구간은 3.7~4.2%, 문제가 있던 4.4가 16.5%였다. 0.0%는 잘 된 것이 아니다.

### 2. others 확률이 소리 내용과 무관하다 (핵심)

others 215개는 AI Hub 37개 카테고리(발걸음·망치질·가구 끄는 소리·세탁기·진공청소기·화장실 물·
샤워·바이올린·피아노·강아지·굴착기·브레이커·덤프트럭·학원 아이들 떠드는 소리 등)인데,
전부 0.108 근처 한 점으로 뭉쳤다. **절반이 0.1063~0.1094 사이, 폭 0.003 안에 들어간다.**

같은 방법을 타겟과 others가 같은 출처(AI Hub 단일)인 두 버전에 적용한 대조 결과:

| 버전 | 타겟 | others sd | 카테고리 평균 폭 | 결정축 폭 | **내용이 쓰는 비율** | 타겟-others 간격 |
|---|---|---|---|---|---|---|
| mark4.1 | heavy_impact | 0.1358 | 0.4276 | 0.8211 | **52.07%** | -0.4863 (겹침) |
| mark4.3 | construction | 0.1605 | 0.3127 | 0.8240 | **37.95%** | -0.7040 (겹침) |
| mark4.5 | media_talking | 0.0057 | 0.0132 | 0.7983 | **1.66%** | +0.5434 (분리) |

"내용이 쓰는 비율" = (AI Hub 카테고리별 평균 확률의 최대-최소) / (결정축 폭).
결정축 폭 = others 최솟값 ~ 타겟 최댓값.

4.1과 4.3은 결정축의 38~52%를 소리 내용이 쓴다. 4.5는 1.66%다.

### 3. 헷갈린 카테고리 순서가 말이 안 된다

`others_prob_by_category.csv` 참조.

- **mark4.1**(발걸음·망치질): 골프퍼팅 0.5216 → 강아지 0.4266 → 문 여닫는 소리 0.4054.
  전부 짧은 충격음. 내용을 듣고 있다.
- **mark4.3**(굴착기·브레이커): 에어컨 실외기 0.4105 → 이륜차 0.3117 → 드럼세탁기 0.2940.
  전부 연속 기계음. 내용을 듣고 있다.
- **mark4.5**: 식기세척기 0.1169(1위) → … → 등하원 아이들 떠드는 소리 0.1055(하위) →
  바이올린 0.1037. 폭 0.0132.
  **`media_talking`의 본질은 사람 말소리인데, others 안에 실제 사람 말소리가 있는데도
  가장 안 헷갈렸다.** 내용을 듣고 있다면 이것이 제일 헷갈려야 한다.

## 2026-08-02 판단이 왜 틀렸나

4.5 출처를 정할 때 채널 지문을 6특징(roll95·roll99·hf6k·hf7k·floor·flat)으로 재서
VOiCES 75.0% 대 같은 출처 대조군(4.3) 71.7%, **순수 채널 이득 +3.3%p**로 보고
"밀도 shortcut(4.1 81.9%, 4.8 77.4%)보다 낮으니 감수 가능"으로 판단했다.

그 탐침이 조잡해서 채널 신호를 과소평가한 것이다. 실제 모델은 같은 신호로 100%를 낸다.
**단순 특징 기반 탐침의 분리율을 모델이 쓸 수 있는 단서의 상한으로 삼으면 안 된다.**

## 그래서 어떻게 했나

타겟과 others를 **같은 녹음 환경**에서 뽑는 구성으로 다시 만들기로 했다(2026-08-08).

- 새 출처: **SINS** (DCASE 2018 Task 5 development set, CC BY-NC-4.0, Zenodo 10.5281/zenodo.1247102)
- 한 사람이 한 집에서 일주일간 생활한 것을 마이크 어레이 4개(DevNode1~4)로 연속 녹음, 활동별 라벨
- 타겟 = `watching_tv` (9세션, 고유 12.95시간)
- others = 같은 집의 비TV 활동 (`social_activity`·`working`·`cooking`·`dishwashing`·
  `vacuum_cleaner`·`eating`). `absence`는 품질 게이트 탈락 예상, `other`는 정의 불분명이라 제외
- split은 **세션 단위**. 같은 시각을 노드 4개가 동시에 녹음하므로 노드로 나누면 누수가 난다
- 수집 스크립트: `preprocessing/sins_slicer.py` (신설)

## 재학습 후 확인할 것

같은 방법으로 표를 다시 만든다. others 확률을 AI Hub 카테고리 대신 **SINS 활동별**로 갈라
"내용이 쓰는 비율"을 잰다. 4.1의 52%, 4.3의 38% 근처면 제대로 학습된 것이고,
1.7% 같은 값이 또 나오면 다른 지름길이 남아 있다는 뜻이다.
