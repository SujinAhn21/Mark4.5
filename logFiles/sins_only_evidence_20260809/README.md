# mark4.5 SINS 단일 출처 구성 — 폐기 전 기록 (2026-08-09)

이 폴더는 **2026-08-08에 만든 mark4.5 SINS 단일 출처 구성**의 학습 결과와 진단을 보존한 것이다.
문제가 있어서 버리는 것이 아니다. 이 구성은 검증을 통과했다. 두 집(SINS + CHiME-Home) 혼합
구성으로 바꾸면서 데이터가 교체되므로, 그 전 상태를 남긴다.

같은 폴더의 `../voices_shortcut_evidence_20260808/` 은 그보다 앞선 VOiCES 구성(실제로 지름길이
있었던 것)의 기록이다. 혼동하지 말 것.

내용을 보고 있다는 뜻이다.

## 그런데 왜 바꾸는가

두 가지가 남아 있었다.

1. **환경이 한 채뿐이다.** SINS는 한 사람이 vacation home 한 채에서 일주일 녹음한 것이 전부라,
   "다른 집에서도 되는가"를 이 데이터로는 물을 수 없다.
2. **SINS는 한 세션이 한 활동이다.** 그래서 타겟과 others가 세션을 공유하는 것이 원천적으로
   불가능하고, 세션 지문 가능성이 구조적으로 남는다. 위 진단으로 정황상 부정됐지만
   구조 자체는 그대로다.

무엇보다 4.5만 출처가 단일이면 논문에서 **"4.5만 왜 이렇게 높은가 / 출처 때문에 맞힌 것
아닌가"** 라는 해명을 계속 해야 한다. Mark5의 media_talking도 같은 문제를 물려받는다.

그래서 CHiME-Home(다른 집, **같은 세션 안에서 TV가 켜졌다 꺼졌다 함**)을 절반 섞어,
두 출처가 타겟과 others 양쪽에 똑같이 들어가게 바꾼다. 출처가 클래스 정보를 주지 못하므로
그 질문이 구조적으로 성립하지 않게 된다. 선정 근거와 세션 배정은
`preprocessing/chime_manifest.py` 머리주석에 실측값과 함께 적어두었다.
